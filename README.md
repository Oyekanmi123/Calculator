# Calculator

A simple calculator app built with vanilla JavaScript that performs basic arithmetic operations.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone the repository
```bash
git clone https://github.com/Oyekanmi123/Calculator.git
```
2. Open the project folder
3. Open `index.html` in your browser
